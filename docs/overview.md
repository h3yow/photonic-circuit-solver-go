# 本地光子电路仿真引擎 — 约定与验证说明

本包（`solver`）在本地模型上仿真由**波导、分束器、移相器、谐振腔**构成的
线性光学电路，提供两种相互独立的传播求解途径、移相器相位标定与漂移补偿，
以及严格的模型版本兼容与并发安全保证。

## 1. 光场与相位约定

- 复场振幅时间因子取 **e^{−iωt}**（物理光学惯例）。
- 长度与波长的**内部单位统一为微米（µm）**：
  - 传播相位：`φ = βL = 2π·n_eff·L_µm / λ_µm`，传播算子为 `e^{+iφ}`；
  - 波导损耗字段 `loss` 单位由模型 `loss_unit` 决定：
    - `db_per_m`（1.0 模型缺省）：先除以 1e6 得 dB/µm；
    - `db_per_cm`：先除以 1e4 得 dB/µm；
    再按 `α = (ln10/10)·loss_dB_per_µm` 换算为奈培/µm，振幅因子 `e^{−αL}`。
- 每个器件满足 `out = S·in`，S 的行列顺序与端口表严格一致：

| 器件 | 输入端口（列） | 输出端口（行） | S 矩阵 |
|---|---|---|---|
| waveguide / phaseshifter | `in` | `out` | 1×1：`e^{−αL+iφ}` / `e^{iφ}` |
| beamsplitter | `a,b` | `c,d` | 实 Hadamard：`[[c,s],[s,−c]]`，`c=cosθ, s=sinθ`；缺省 θ=π/4（50:50），亦可给 `reflectivity`（θ=arcsin√R，R∈[0,1]） |
| resonator（add-drop） | `in,add` | `through,drop` | 见下 |

- 谐振腔采用往返场解析消除的 add-drop 模型（无耗且对称耦合时幺正）：
  - 记 `D = 1 − r_self·r_cross·a·e^{iφ_rt}`，`κ = √((1−r_self²)(1−r_cross²))`；
  - `S = (1/D) · [[r_self − r_cross·a·e^{iφ}, −κ·a·e^{iφ}], [−κ·a, r_cross − r_self·a·e^{iφ}]]`；
  - 参数边界：`0 < r_self, r_cross < 1`，`0 < a ≤ 1`；
    当 `|D| < 1e-12`（过于接近奇异极点）时拒绝编译，避免非有限/非物理放大。

谐振腔的反馈在器件内部解析消除，因此**器件连接图仍必须是有向无环图**；
连接层的有向环按 `TOPOLOGY_CYCLE` 拒绝。

### 外部端口与功率

- 连接是从“输出侧”到“输入侧”的有向边；外部端点出现在 `from` 侧即外部
  **输入**，出现在 `to` 侧即外部**输出**。
- 单模端口不可扇出/扇入：任何器件端口与外部端口都必须被恰好一条连接占用，
  否则分别报 `PORT_DIMENSION_MISMATCH` / `DANGLING_CONNECTION`。
- 输出功率定义为 `P = |A|²`。无耗电路（a=1、loss=0、纯分束/相移）总功率守恒。

## 2. 两种独立传播求解途径与容差

1. **拓扑途径（`topological`）**：Kahn 拓扑序上逐器件传播，只做矩阵-向量乘，
   不装配任何全局矩阵。
2. **全局途径（`global`）**：为内部波变量装配线性方程组 `(I−Q)e = b`，
   带部分主元的复数高斯消元求解，再重建所有器件输出。

两条途径共享的只有器件 S 块的数值；**装配、排序、数值算法完全独立**。

- 默认方法为 `crosscheck`：同时运行两者并逐端口比较，判定式
  `|a−b| ≤ tol·max(1,|a|,|b|)`，默认 `tol = 1e-9`（`Limits.SolverTolerance`）。
- 超差时返回 `SOLVER_DIVERGENCE`，绝不静默选取其一；错误 Detail 同时携带
  输入振幅、分歧端口、两条途径各自的完整结果，作为判定依据。
- 全局方程奇异或过程中出现 NaN/Inf 时分别报 `SOLVER_DIVERGENCE` /
  `NON_FINITE_INPUT`。

## 3. 输入的物理边界

- 激励必须为有限复数，`|A| ≤ Limits.MaxInputAmplitude`（默认 1e6）；
  越界报 `OUT_OF_BOUNDS`，**不做静默截断或归一化**。
- 移相器控制量/相位必须有限且 `|v| ≤ Limits.MaxControl`；同一移相器不得同时
  提供控制量与显式相位（语义互斥，报 `INVALID_PARAMETER`）。
- 器件参数（波长、长度、n_eff、反射率、谐振腔系数等）在编译期做有限性与
  物理范围校验，缺失必填参数报 `INVALID_PARAMETER`，不做默认值兜底。
- 可选参数的缺省语义只在编译期登记一次（如分束器 θ=π/4、波导 loss=0、
  移相器 u0=0/k=1/gamma=0/phi0=0、谐振腔 phi_roundtrip=0）。

## 4. 相位标定与漂移补偿

模型（中心化二次式，控制量 u）：

```
φ(u) = c0 + c1·(u−ū) + c2·(u−ū)²
```

- 至少 3 个标定点；控制量必须**严格递增**，测量相位顺序展开到连续分支后必须
  **单调不减**（否则 `CALIB_NO_SOLUTION`）。
- 最小二乘拟合（中心化设计避免数值漂移）；3×3 正规方程奇异
  （采样退化）或在覆盖区间上导数不恒正（非单调可解释）=> `CALIB_NO_SOLUTION`。
- 最大拟合残差超过 `1e-6 rad` => `CALIB_NO_SOLUTION`（样本不自洽）。
- 漂移点必须落在标定覆盖区间内；漂移量为各复测点残差（wrap 到 (−π,π]）的
  确定性均值，参与目标补偿：`want = target − drift`。
- 可达相位区间是标定覆盖的连续区间 `[φ(u_lo), φ(u_hi)]`；目标按模 2π 取唯一
  代表元后仍超出区间 => `CALIB_OUT_OF_RANGE`，绝不外推。
- 反演为区间二分，确定性初始界 `[u_lo,u_hi]`（无随机数、无外部状态），
  相位残差容差 `1e-10 rad`；达到 `Limits.MaxCalibIterations`（默认 100）仍未
  收敛 => `CALIB_NOT_CONVERGED`，不返回未收敛/发散的控制量。
- 相同输入重复标定的结果逐位一致（迭代次数也一致）。

## 5. 模型版本支持范围

| 版本 | 支持状态 | 语义 |
|---|---|---|
| `1.0` | 可读，自动迁移到内部 1.1 | 无 `loss_unit` 字段；缺省 **db_per_m**，语义确定稳定 |
| `1.1` | 当前版本 | 新增可选 `circuit.loss_unit`（`db_per_m`/`db_per_cm`） |
| 其它（`2.0`、`1.2`、`0.9`、空、非字符串…） | 拒绝 | `VERSION_UNSUPPORTED` |

- JSON 全层级严格解码：未知顶级/嵌套字段、未知器件参数、尾随数据均报
  `UNKNOWN_FIELD`（不会静默丢弃或猜测）。
- **前向不兼容检测**：1.0 文档若携带 1.1 才引入的 `loss_unit`，报
  `MODEL_MIGRATION`（旧版本文档出现新字段时语义无法确定）。
- 未知器件类型、必填字段缺失、字段 JSON 类型错误均给出分类错误。
- 版本号必须显式声明；迁移只做字段补齐与单位归一化，不改变任何计算结果的
  解释方式。

## 6. 规模上限与失败策略

`Limits`（`Option` 覆盖，启动时校验为严格正值；默认值）：

| 项 | 默认 | 超限行为 |
|---|---|---|
| `MaxDevices` | 4096 | `LIMIT_EXCEEDED`，模型拒绝 |
| `MaxConnections` | 8192 | 同上 |
| `MaxBatchSize` | 1024 | 请求拒绝；已完成的前序批元素不返回（无部分结果） |
| `MaxCalibIterations` | 100 | 反演报 `CALIB_NOT_CONVERGED` |
| `SolverTolerance` | 1e-9 | — |
| `MaxInputAmplitude` | 1e6 | `OUT_OF_BOUNDS` |
| `MaxControl` | 1e6 | `OUT_OF_BOUNDS` |

- 所有拒绝发生在任何结果返回之前；求解器不打开文件/句柄/goroutine，
  临时矩阵与场向量均在请求调用栈内分配，失败路径无残留计算结果、无资源泄漏。
- `context.Context` 已取消时入口立即返回。

## 7. 并发模型

- `Engine` 创建后只读；`CompiledCircuit` **不可变**。
- 每次 Solve/Calibrate 的散射块、场向量、全局矩阵均为**请求内独立分配**，
  编译结果与缓存跨请求零共享；不存在半更新状态、缓存数值漂移或重复标定。
- 同一电路可被任意数量 goroutine 并发求解/标定，结论逐位一致。

## 8. 验证方法

运行全部测试（推荐带竞态检测）：

```sh
go test ./... -count=1
go test -race ./... -count=1
go vet ./...
```

测试重点对应需求：

- `topology_test.go`：端口缺失、维度不匹配/扇出、方向错误、悬空、重复 ID、
  成环、外部端口输入/输出冲突——每类错误码独立可区分；
- `calibrate_test.go`：收敛与可复现、漂移补偿、模 2π 等价目标、非单调/样本
  不足/不自洽/超范围/非有限/迭代上限，并验证标定结果回灌 Solve 的端到端闭环；
- `version_test.go`：1.0 缺省、1.1 显式单位、旧文档携带新字段、不支持版本、
  未知字段/参数/器件类型、尾随数据；
- `input_limits_test.go`：非有限/越界激励、未知端口、批量与器件数上限、
  移相器双重设置、物理参数边界（含谐振腔极点）；
- `concurrency_test.go`：64 goroutine × 20 轮并发求解、并发标定、并发独立
  载入，逐位一致性（`-race` 下通过）；
- `divergence_test.go`：两途径一致时通过，注入确定性扰动后必须报
  `SOLVER_DIVERGENCE` 且携带输入与双方结果；
- `mzi_test.go` / `resonator_test.go`：MZI 干涉极值与功率守恒、分束器
  幺正性、谐振腔共振条件（through=0/drop=1）及闭式公式逐项比对。

所有断言失败时打印**输入模型/输入数据**与**错误码 + Detail 判定依据**。
