# 光场与相位约定

本文件固定引擎的数值约定。不同求解入口（线性全局求解、拓扑顺序扫描、Jacobi
迭代）与标定/补偿共享同一套约定，因此同一电路在合理参数下结论一致。

## 1. 时间与传播相位

- 时间依赖取 **exp(−i·ω·t)**。
- 沿波导正向传播累积相位 **exp(+i·β·L)**（模型中直接以 `phase = β·L`（弧度）给出）。
- 功率定义为复振幅模方 `P = |a|²`。所有内置器件均无源（passive），总输出
  功率不得超过总输入功率；求解结束后会做功率守恒校验，违反时报
  `solver_divergence`，不返回非物理结果。

## 2. 端口与场变量

- 所有内置原语均为**单模**，每个端口恰好承载一个复振幅。模型显式声明
  `modes != 1` 时按 `port_dimension_mismatch` 拒绝。
- 全局端口变量 `x[p]` 表示在端口 p **进入器件**的波。
  - 外部输入端口：`x[p]` 固定为激励振幅 `src[p]`；
  - 外部输出端口：`x[p] = 0`（无注入）；
  - 连接端口 p（与 q 相连）：`x[p]` 等于对端器件在 q 的出射波。
- 器件局部满足 `b = S · a`（`a` 为进入波，`b` 为出射波）。

## 3. 器件散射矩阵

端口顺序：二端口器件为 `[in, out]`；分束器为 `[in1, in2, out1, out2]`。

- **波导 / 移相器**（互易二端口，正反方向同相移）：

  ```
  S = [[0, f],
       [f, 0]],  f = exp(i·φ)
  ```

  - 波导：`φ = phase`
  - 移相器：`φ = bias + offset`（标定结果写入 `offset`；`gain` 为控制增益，
    缺省 1 rad/控制单位，必须为正）

- **分束器**（对称、互易、幺正），`t = cos(θ)` 为直通振幅、`r = sin(θ)` 为
  交叉振幅，**π/2 相位只落在交叉臂**：

  ```
  out1 = i·r·in1 + t·in2
  out2 = t·in1 + i·r·in2
  ```

  θ ∈ [0, π/2]；缺省 θ = π/4（50:50）。50:50 时 MZI 传输率
  `P_out1 = sin²(φ/2)`、`P_out2 = cos²(φ/2)`。

- **全通环形谐振腔**（总线二端口，互易）：

  ```
  t(φ) = (r − a·exp(−i·φ_round)) / (1 − a·r·exp(−i·φ_round))
  ```

  `r` 为自耦合振幅（|r| < 1），`a` 为环程损耗振幅（0 < a < 1），
  `φ_round` 为单环程相位。边界点 |r|=1 / a=1 被排除以保证有限线宽与严格
  无源，参数越界按 `out_of_physical_range` 拒绝。

## 4. 激励的物理边界

- 激励振幅必须为有限复数（NaN/±Inf → `non_finite_input`）。
- 归一化约定下，**每个**激励功率 `|a|² ≤ 1`，且总输入功率 `Σ|a|² ≤ 1`，
  否则按 `out_of_physical_range` 拒绝（不做静默截断）。

## 5. 标定的相位约定

- 被调量为 `δ = arg(probe) − arg(reference)`，主值统一缠绕到 `(−π, π]`。
- reference 可取外部输入端口（即稳定的零相位激励），也可取非暗的输出端口。
- 搜索在给定 offset 区间 `[low, high]` 上把周期相位铺到**一条连续单调分支**
  后二分；可达区间之外的目标报 `calibration_out_of_range`，绝不返回缠绕后
  误导性的“看似可达”值。
